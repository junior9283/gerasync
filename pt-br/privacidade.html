Política de Privacidade do GeraSync

Atualizada em 7 de novembro de 2026

O GeraSync for Google Drive ("GeraSync") é um cliente não oficial do Google Drive para Linux, de código aberto (GPL-3.0). Ele não tem ligação com o Google nem aprovação dele. Esta política explica quais dados o GeraSync acessa, como os usa, guarda e compartilha, e como você pode apagá-los.

Dados que o GeraSync acessa

No login, o GeraSync pede ao Google estas permissões:

  • Google Drive (https://www.googleapis.com/auth/drive): a lista dos seus arquivos e pastas no Meu Drive e nos Drives compartilhados a que você tem acesso, os metadados deles (nomes, pastas, tamanhos, datas, revisões, compartilhamento) e o conteúdo dos arquivos que você abre, marca como off-line ou sincroniza.
  • Seu endereço de e-mail e o identificador da conta (openid, email): para mostrar qual conta do Google está conectada e manter separados os dados de cada conta.

Como o GeraSync usa os dados

Só para oferecer os recursos que você vê no app: mostrar o Drive como uma pasta no computador, abrir arquivos, enviar as alterações que você faz nessa pasta, manter arquivos disponíveis off-line, espelhar ou fazer backup das pastas que você escolhe e, quando você pede, compartilhar um arquivo, mostrar as versões, criar um atalho ou criar um Drive compartilhado. O GeraSync não usa seus dados para publicidade, não os vende e não monta perfis com eles.

Onde os dados ficam

Só no seu computador:

  • Os metadados dos arquivos, num banco local, para a pasta abrir sem consultar o Google a cada acesso.
  • O conteúdo que você abriu ou marcou como off-line, num cache local, até ser liberado.
  • O token de login de cada conta conectada (até 4), no chaveiro do sistema (Secret Service), nunca em arquivo de texto.
  • As preferências e os registros do app, nas pastas de configuração e de estado do seu usuário.

Os dados trafegam entre o seu computador e o Google por conexões cifradas (HTTPS).

Compartilhamento

O GeraSync não tem servidor. O desenvolvedor nunca recebe, guarda nem lê seus dados do Google, e o GeraSync não os transfere a ninguém. O app só conversa com:

  • as APIs de login e do Google Drive, do Google;
  • uma vez por dia, a API pública do GitHub, só para saber a última versão do app (api.github.com/repos/junior9283/gdrive-desktop-linux/releases/latest). O pedido leva apenas a versão instalada, nenhum dado seu.
  • quando você escolhe Atualizar agora, o GitHub de novo, para baixar da página da versão o pacote do app, o SHA256SUMS e a assinatura dele. Nada seu vai junto; o pacote só é instalado se a assinatura do projeto e a soma conferirem.

O GeraSync não envia estatísticas de uso nem telemetria. "Enviar feedback" e, com o relatório de erros ligado (vem desligado), "Enviar relatório" só abrem no navegador a página de issues do projeto com o texto preenchido; quem decide publicar é você. O pacote de diagnóstico fica no seu computador.

Uso limitado

O uso e a transferência para qualquer outro app das informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. Em especial, os dados são usados só para os recursos descritos acima; não são transferidos a terceiros, a não ser quando necessário para esses recursos, para cumprir a lei ou numa fusão ou aquisição; não são usados para publicidade; e ninguém os lê, a não ser que você peça ajuda e autorize, ou quando for necessário por segurança ou para cumprir a lei.

Como apagar seus dados ou revogar o acesso

  • No GeraSync, abra o menu da conta e escolha Desconectar a conta. O token, o cache e os arquivos off-line daquela conta saem do seu computador.
  • Desinstalar o GeraSync pela janela dele remove os programas; as preferências em ~/.config/gerasync podem ser apagadas à mão.
  • Você pode revogar o acesso do GeraSync a qualquer momento em myaccount.google.com/permissions.

Os seus arquivos no Google Drive seguem os termos do próprio Google e não são tocados quando você desconecta ou desinstala o app.
